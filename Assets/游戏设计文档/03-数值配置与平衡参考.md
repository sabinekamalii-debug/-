## 第七部分 · 关键战斗公式

| 公式 | 说明 |
|------|------|
| `reduction = Min(0.99f, defense / 10000f)` | 防御减伤：100防御=1%减伤，上限99% |
| `soul = DeathConsolationBase + stagesCleared × DeathConsolationPerStage` | 死亡返还魂 = 1 + 通关层数 |

| 暴击基础倍率 = 150% | `CritChanceBonus` / `CritDamageBonus` 在此基础叠加 |

## 第九部分 · 数值设计汇总工具

> 说明：原 `ValueLogger`（运行期数值变动日志）已移除。以下为面向「数值平衡」的开发者工具。

### 1. 数值设计一览（DesignValueSummary）— 主用
把后台**设计好**的所有数值初始值聚到一个文件，供做平衡：
- 工具：`Assets/Editor/DesignValueSummary.cs`
- 产物：`Assets/游戏设计文档/数值设计汇总.csv`（Excel 打开，可筛选/排序）+ `数值设计汇总.md`（分章节宽表，一眼看）
- 覆盖范围：干员(OperatorData)、敌人(EnemyData2)、天赋卡(TalentCardData)、天赋树(TalentTreeData)、肉鸽平衡常量(BalanceConfig)
- 刷新：编译后 / 保存 .asset 后自动更新；或菜单 `Tools → 数值设计汇总 → 全部导出`

### 2. 自动数值报告（BalanceScanner）— 技术向
扫描全部数值字段（含运行时组件与 .asset 实测值）生成技术报告：
- 工具：`Assets/Editor/BalanceScanner.cs`，输出：`Assets/塔防脚本/肉鸽/BALANCE_REPORT.md`（自动生成，请勿手动编辑）
- 刷新：编译后自动更新，或菜单 `Tools → 刷新数值报告`
