# 卡牌与角色设计

> 本文档整合自原 `CardDesignDoc.md`、`干员职业设计.txt`、`敌人种类设计.txt`，
> 并吸收各卡牌草稿（攻击/防御/守护/技能/稀有/特殊/组合升级）中仍然有效的创意方向。
>
> **设计基准（与代码一致）**：卡牌无费用、无稀有度等级；采用「全局 / 职业 / 专属」三层混合方案；
> 全局卡必须百分比；职业/专属卡带购买冷却副作用。所有旧的"稀有度 cost1-4 + 升级路径"框架已废弃。

---

## 第一部分 · 卡牌系统

### 1. 设计理念

- **三选一抽卡**：每次从卡池随机抽 3 张选 1 张，可跳过；选卡完全免费（不消耗点数）。
- **六类卡牌**：攻击 / 防御 / 守护 / 技能 / 稀有 / 特殊。
- **无稀有度等级**：每张卡都独特，没有普通/进阶/稀有/传奇的品质分级。强度差异由「作用范围 + 副作用」平衡，而非品质。
- **每局 5~8 张**：一局约打 5~7 场战斗，每场胜利 +1 次抽卡，所以单卡效果必须有明显体感。
- **组合技导向**：卡牌带标签(Tags)，同标签凑齐触发额外组合效果（系统后续细做）。
- **全局卡必须百分比**：全局效果只能用百分比加成，不能用固定数值，保证对所有干员公平（避免低攻干员收益爆炸）。

### 2. 混合型作用域方案

| 层级 | 占比 | 作用范围 | 副作用 | 说明 |
|------|------|---------|--------|------|
| 全局卡 | ~67% | 所有干员 | 无 | 保证基础体验，带任何干员都有用 |
| 职业卡 | ~25% | 特定职业干员 | 该职业干员购买冷却 +15 秒 | 策略深度核心，选干员与选卡联动 |
| 专属卡 | ~8% | 指定干员 | 该干员购买冷却 +60 秒 | 量少但强力，改变该干员玩法 |

> **副作用逻辑**：职业/专属卡效果更强，但延长对应干员购买冷却，避免无脑拿强卡。专属卡冷却惩罚极大，只有核心 build 正好围绕该干员时才值得拿。
>
> **重要开发约束**：干员实例尚不完整（后续慢慢制作），因此优先做全局卡（`CardEffectTarget.Global`）或按职业(OperatorType)生效的卡，避免依赖具体干员实例，保证未来新干员自动接入。专属卡先用模板占位。

### 3. 卡牌作用域（CardScope）

| 作用域 | 说明 | 清除时机 |
|--------|------|---------|
| `PerRun` | 本局生效 | 本局结束（通关/死亡） |
| `PerBattle` | 仅本次战斗 | 本次战斗结束（红字标注，如守护点回溯救场卡） |

### 4. 标签系统（组合技核心）

每张卡带 0~3 个标签（通用基础卡 0~1、流派核心卡 1~2、复合机制卡 2~3）。同标签凑齐 **3 张** 触发组合奖励：

| 标签 | 组合效果（3 张触发） |
|------|---------|
| 烈焰 Fire | 所有攻击附带灼烧（3 秒内额外造成 50% 攻击力伤害） |
| 寒冰 Ice | 攻击 30% 概率减速敌人 50% 持续 2 秒 |
| 雷电 Lightning | 攻击弹射至 2 个额外目标，各造成 50% 伤害 |
| 鲜血 Blood | 干员攻击吸血 15% |
| 坚壁 Fortress | 防御效果翻倍 |
| 圣盾 Aegis | 守护点获得护盾，抵消 3 次伤害 |
| 疾风 Swift | 全体攻速 +30% |
| 暗影 Shadow | 攻击无视 50% 防御 |
| 自然 Nature | 守护点每秒回 1HP |
| 机械 Machine | 部署费用 -30% |
| 狂战 Berserk | 干员 HP <50% 时攻击力翻倍 |
| 战术 Tactic | 每场战斗开始时所有干员技能 SP +50% |

组合规则：多标签可同时生效；同标签只触发一次（4 张烈焰不触发两次）。阈值可实测调整。

### 5. 六大卡牌类型（第一版 72 张 = 每类 12 张 = 8 全局 / 3 职业 / 1 专属）

数值锚点：攻击 10 / HP 100 / 防御 0（100 防御 = 1% 减伤）/ 攻速 1.0s / 射程 3.5 / 守护点 5~10HP。
平衡区间：全局卡无条件 ≈ +15%~25%，有条件触发 ≈ +40%~60%；职业卡 ≈ +35%~50%；专属卡 ≈ +100%+。

### 6. 守护点回溯救场卡系统

守护点受致命伤时触发时光回溯（每局 1 次，回退 5 秒），从专用救场卡池 3 选 1（**不能跳过**），均为 `PerBattle`。触发类型（`GuardianRewindTriggerType`）：
- **即时型**：获得 DP / 回复守护点 HP / 回复全体干员 HP / 冻结全场敌人 / 伤害全场敌人 / 击杀最弱敌人。
- **战斗 buff 型**（本场持续）：攻击 +X% / 攻速 +X%。

### 7. 卡牌代码架构现状

已实现效果类型 `TalentEffectType`（19 种）：AttackBonus / DefenseBonus / GuardianHpBonus / AttackPercent / DefensePercent / GoldBonus / ScoreBonus / AttackSpeedPercent / AttackRangeBonus / DefensePenetration / CritChanceBonus / CritDamageBonus / LifeStealPercent / EliteDamageBonus / MaxHpPercent / KillStackAttack / LowHpAttackBonus / KillAttackSpeedBuff / AoeRangePercent。

- 每张卡支持「主效果 + 副效果」双槽位，每效果含 value1 / value2 两参数。
- 作用范围 `CardEffectTarget`：Global(0) / ByClass(1) / ByOperator(2)，配套字段 `effectTarget` / `targetOperatorType` / `targetOperatorDataId` / `purchaseCooldownPenalty`。
- 作用域 `CardScope`：PerRun(0) / PerBattle(1)。
- 数据结构 `TalentCardData`：`cardId` / `displayName` / `description`（已移除 `costRunPoint`，天赋卡免费化）。

已完成 ✅：天赋卡免费化、移除稀有度、CardScope、守护点回溯系统(8 种触发)、一次性战斗 buff 自动清除、混合型数据结构、19 种效果类型枚举、六类各 12 张设计。

待实现 🔄：攻击/防御/技能卡效果接入干员战斗系统；守护卡接入 `DefensePointShooter`/`GameManager`/`TeleportController`；职业系统扩展；批量创建 `.asset`；标签/组合技系统；专属卡效果接入；从双槽位扩展为效果列表（支持 3+ 复合）。

### 8. 卡池扩展创意库（未实装设想，供后续填充 72 张之外的内容）

> 以下为从旧草稿提炼的、仍然合理的创意方向。**框架必须遵循本文档新方案**（无稀有度、全局百分比、职业/专属副作用），旧草稿的 cost 分级与升级路径已废弃。

- **攻击流派**：弹射连锁（雷电）、蓄力重击、穿透直线、暴击处决（对低血敌 +伤害）、连击叠伤、破甲穿甲、先手爆发、追击移动目标、标记增伤。
- **防御流派**：反伤荆棘、格挡减伤、闪避、低血续航、精英抗压、护盾抵消。
- **守护点流派**：AOE 反击、护盾、回溯强化、传送机动、与职业干员的联动反击/协同射击。
- **技能流派**：SP 充能、自动释放、技能连锁攻速、低血技能爆发、技能结束返 SP。
- **元素/标签共鸣**：烈焰灼烧、寒冰减速、雷电弹射、鲜血吸血等，凑齐同标签触发全队增益（对应第 4 节）。
- **特殊/元机制**：经济加成、抽卡强化、重抽、跳过战斗、卡转金币、下一张卡强化。

## 第二部分 · 干员职业设计（七职业）

职业枚举（`OperatorData.cs`）：`Vanguard=0 先锋 / Guard=1 近卫 / Defender=2 重装 / Sniper=3 狙击 / Caster=4 术师 / Medic=5 医疗 / Specialist=6 特种`。

**核心原则**：每个职业在"机制"上不可替代，避免"可有可无"。伤害唯一入口 `Enemy2.TakeDamage`（支持 isMarked ×1.3、ignoreDefense 穿透），破甲/增伤/标记类机制一律通过「组件 + 标记位」落地，不改核心战斗循环。

### 一句话分工闭环

先锋(回费/机动/铺场) → 重装(扛线/多挡/控场) → 近卫(近身斩杀/单挑爆发) → 狙击(远程速攻/暴击/清杂，不破甲) → 术师(远程破甲/穿透) → 医疗(治疗/续航/增益) → 特种(位移/推拉/特殊机制)。

区分逻辑（防重叠）：
- 近战三兄弟靠「阻挡数 + 攻防权重」区分：先锋阻挡 0（穿过不挡）、近卫阻挡多但单挑强、重装阻挡最多只扛不输出。
- 远程两兄弟靠「是否破甲」区分：狙击不破甲（吃敌人防御减伤）、术师破甲（专破高防重甲）。
- 敌人「防御值」因此真正有意义：高防重甲怪能顶住先锋/近卫/狙击，只有术师能凿穿。

### 各职业

| 职业 | 状态 | 定位 | 核心特性 | 别和谁撞 |
|------|------|------|---------|---------|
| **先锋 Vanguard** | 已实现 | 经济/机动/铺场 | 不阻挡(currentBlockCount=0)高速穿插；侦察标记(`VanguardRecon.cs`，敌进入半径被标记，受伤 ×1.3)；回费方向(新写返还 DP 的 OperatorSkill 调 `DeploymentManager.AddDP()`) | 重装(先锋不挡、重装专挡) |
| **近卫 Guard** | 已实现 | 近身斩杀/单挑爆发 | 可阻挡多个(maxBlockCount 2~3)；**专注状态**(`GuardTrait.cs`，恰好只挡 1 个时变色+攻速×1.5)；不做群攻 | 重装(近卫输出、重装只扛)、术师(近卫近身、术师远程) |
| **重装 Defender** | 设计方向 | 队伍的"墙"与控场锚点 | 高减伤(runtimeDefense，减伤=defense/10000 封顶 99%)；多阻挡(maxBlockCount=3)；高血低速低攻不回费。技能方向：不动如山/援护嘲讽/荆棘反伤/护盾分摊(基于 `Skill_GoldenDefense` 扩展) | 先锋(不挡)、近卫(要输出) |
| **狙击 Sniper** | 设计方向 | 后排高台速攻/脆皮清道夫 | 远程高台不阻挡；超远射程；高攻速；**高暴击签名**(新增 `OperatorData.baseCritChance` 20~30%，接现有暴伤 150%)；**严格不破甲**(不挂 IgnoreDefenseAttacker，正常吃减伤)。可选签名「精准锁定」(镜像近卫，唯一游离敌时攻速/暴击强化) | 术师(狙击物理吃防御、术师法术破防) |
| **术师 Caster** | 设计方向 | 远程破甲/穿透专精 | 中远射程；**常驻破甲签名**(预制体挂 `IgnoreDefenseAttacker`，`GetPenetrationPercent` 生效)；法术单发偏慢偏贵稳定破防，不走暴击 | 狙击(是否破甲)、近卫(远程/近身) |
| **医疗 Medic** | 设计方向 | 治疗/续航/增益 | 治疗(isHealer + `AreaHealer.cs`，可群疗/光环)；增益光环进阶(范围友军加攻速/减伤)；远程后排需保护 | 与所有输出互补，专职续航 |
| **特种 Specialist** | 设计方向 | 位移/推拉/特殊机制 | 位移推拉(把敌推出路线/拉入陷阱)；对特定敌种特攻走 Global 卡按 OperatorType 生效；工具人机制(回费/封路/召唤) | 机制独特，天然不重叠 |

**破甲三态对照**：术师=常驻破甲；近卫=技能临时破甲(`Skill_PenetrateDefense`)；狙击/先锋=不破甲。四个攻击出口(近战/远程/光波/接触)统一读 `OperatorUnit.IgnoresDefense`。

**可复用零件**：OperatorBrain.moveSpeed、MoveRoutine、IsEvading、Path/wayPoint 路点、UnitBlocker、OperatorUnit.ApplyDefense、RangedAttacker、AoEAttacker、CalculateDamage、GetCritChancePercent、IgnoreDefenseAttacker、GetPenetrationPercent、AreaHealer、OperatorSkill 抽象类、Skill_GoldenDefense、DeploymentManager.AddDP()、已实现特质组件 VanguardRecon / GuardTrait。

## 第三部分 · 敌人设计（七原型 · 反向克制干员）

**设计哲学**：干员是 7 个"答案"，敌人是 7 道"题"。每种敌人"点名"逼玩家出某职业；克制关系刻意做成**双向**，没有万能职业，逼出 Build 深度。

预制体位置 `Assets/Resources/人物/敌人/`，数据资产 `Assets/数据2/敌人数据/`（各 7 个中文名）。做法：复制 `哥布林.prefab` 魔改，改名 + 改 `Enemy2.data` 引用的 EnemyData2。特殊行为由数据开关驱动，`Enemy2.Start()` 运行时自动挂组件（无需手动挂）：`penetrateDefense=true`→IgnoreDefenseAttacker；`rangedAttack=true`→EnemyRangedAttacker(目标图层 "My")；`healRadius>0`→EnemyHealerTrait。

### 分层结构

- **普通层**：7 原型即普通怪池，每关按路线类型抽 2~3 种组波（如「狗群+重甲」「远程+疾跑」「奶妈+杂兵潮」）制造组合题。
- **精英层**：复用 `Enemy2.ApplyEliteBuff(hpMult, defBonus, bonusDP)` 直接套任意原型，不新增种类（重甲兵精英=更厚甲、奶妈精英=更强治疗）。
- **Boss 层**：Boss = 2~3 原型机制叠加，沿用现有魔王（火之魔王≈重锤+术师怪；空之魔王≈远程+召唤杂兵潮；黑之魔王分身≈疾跑量产）。

**加新怪标准流程**：① EnemyType.cs 末尾追加枚举(保旧值不变) → ② 复制哥布林.prefab 改名+改 data guid → ③ 新建 EnemyData2 填数值与开关 → ④ Spawner.cs 加池字段+常量+switch 分支 → ⑤ 克隆预制体拖进对应池。特殊行为由 Enemy2 按数据自动挂组件。
