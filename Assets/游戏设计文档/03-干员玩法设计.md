# 干员玩法设计

> 参考明日方舟肉鸽（集成战略）模式，结合本项目已有架构（OperatorData / DeploymentManager / RogueRuntimeState / 天赋卡 / 金币商店 / StS 分叉地图），设计一套完整的干员持有、获取、升级、升星系统。

---

## 一、设计概述

### 1.1 两套系统各司其职

| 系统 | 定位 | 对标 | 获取方式 |
|------|------|------|---------|
| 天赋卡 | 遗物（被动加成） | 杀塔2 遗物 / 以撒 道具 | 战后 3 选 1（现有系统不变）+ 商店购买 |
| 干员 | 角色阵容（战斗单位） | 明日方舟 干员 | 开局自选 + 剧情获取（主）+ 奇遇/商店概率（辅） |

### 1.2 设计目标

1. **开局自选**：玩家在 RogueEntry 场景从已解锁的干员中自由搭配初始队伍
2. **星级 1~5**：干员分 1~5 星，初始都是 1 星状态，但按最高星级上限不同，1 星的实力也有差别
3. **星数预算 7**：选中干员的当前星数总和不超过 7，约束队伍强度
4. **星级强化**：消耗金币提升干员星级（1→2→...→上限），5 星干员最多接受 4 次强化
5. **剧情获取（主）**：约一半干员通过剧情事件获取
6. **概率获取（辅）**：奇遇/商店概率出现，偶尔有策划安排的剧情事件
7. **单实例部署**：每名干员同时只能 1 个在场，撤退/阵亡后需等再部署冷却
8. **跨大局继承**：通关大局后选 5 名干员带入下一个大局，其余因剧情离队

### 1.3 核心设计原则

- **不破坏现有战斗循环**：OperatorCard 拖拽部署、DP 费用系统、OperatorUnit 战斗逻辑保持不变
- **不引入新货币**：只用现有金币（RunGold）
- **天赋卡 = 遗物**：战后 3 选 1 只出天赋卡，不混入干员
- **干员 = 角色**：开局自选 + 剧情获取，有叙事重量
- **策划主导**：干员获取点由策划手动配置在 ActConfig 中

## 二、干员星级体系

### 2.1 星级定义（1~5 星）

| 星级 | 对标明日方舟 | 定位 | 强化次数 | 数量 |
|------|-------------|------|---------|------|
| ★ | 1~2★ | 炮灰/工具人 | 最多 1 次强化到 ★★ | ~6 |
| ★★ | 3★ | 低费铺场/过渡用 | 最多 1 次强化到 ★★★ | ~10 |
| ★★★ | 4★ | 中坚战力 | 最多 1 次强化到 ★★★★ | ~7 |
| ★★★★ | 5★ | 核心战力 | 最多 1 次强化到 ★★★★★ | ~4 |
| ★★★★★ | 6★ | 决战单位/隐藏角色 | 已满星，不可强化 | ~2 |

> **关键设计**：所有干员初始都是 1 星（当前星级 = 1），但 `maxStarRating`（最高星级上限）不同。一个 maxStarRating=5 的干员在 1 星状态比 maxStarRating=2 的干员在 1 星状态更强——星级上限代表了干员的潜力，1 星只是起点。

### 2.2 1 星状态下的实力差异

干员在 1 星时的基础属性由 `maxStarRating` 决定倍率：

```
1 星基础属性 = OperatorData 原始值 × baseStatMultiplier(maxStarRating)

maxStarRating=1: ×0.6   (炮灰级，极弱)
maxStarRating=2: ×0.8   (过渡级，偏低)
maxStarRating=3: ×1.0   (标准级，正常)
maxStarRating=4: ×1.3   (精英级，偏强)
maxStarRating=5: ×1.6   (核心级，很强)
```

> 即使都是 1 星，一个 5 星上限的干员（×1.6）比一个 1 星上限的干员（×0.6）强近 3 倍。这让高星上限的干员即使没强化也值得带上。

### 2.3 星级强化

消耗金币提升干员当前星级（currentStar → currentStar+1），每提升 1 星全属性大幅增长：

```
强化后属性倍率 = baseStatMultiplier(maxStarRating) × starGrowth(currentStar)

starGrowth: ★=1.0, ★★=1.3, ★★★=1.7, ★★★★=2.2, ★★★★★=3.0
```

| 当前星级 | → 下一星级 | 属性倍率变化 | 强化费用 |
|---------|-----------|------------|---------|
| ★1 | → ★2 | ×1.0 → ×1.3 | 20 金币 |
| ★2 | → ★3 | ×1.3 → ×1.7 | 50 金币 |
| ★3 | → ★4 | ×1.7 → ×2.2 | 100 金币 |
| ★4 | → ★5 | ×2.2 → ×3.0 | 200 金币 |

> 强化受 `maxStarRating` 限制：maxStarRating=2 的干员最多强化到 ★2，maxStarRating=5 的干员最多强化到 ★5（4 次强化）。

### 3.4 星数预算系统

| 参数 | 值 | 说明 |
|------|-----|------|
| 星数预算上限 | 7 | 所有选中干员的 currentStar 之和不超过 7 |
| 最少选择数量 | 1 | 至少选 1 名干员才能出发 |
| 最多选择数量 | 无限制（受星数预算约束） | 理论上最多 7 名 1 星干员 |

**示例组合**：

| 组合 | 星数 | 说明 |
|------|------|------|
| 1 名 ★5 + 1 名 ★2 | 5+2=7 | 极限单核 + 辅助 |
| 1 名 ★3 + 2 名 ★2 | 3+2+2=7 | 均衡阵容 |
| 3 名 ★2 + 1 名 ★1 | 2+2+2+1=7 | 多人铺场 |
| 7 名 ★1 | 1×7=7 | 人海战术 |

> 开局时所有干员都是 1 星（currentStar=1），所以初始预算 = 选中数量 × 1。随着游戏中花费金币强化星级，星数会增长，但开局预算 7 限制了初始队伍规模。

### 3.5 干员解锁状态

干员解锁是**永久的**（跨大局保留）：

| 状态 | 说明 |
|------|------|
| 已解锁 | 玩家可通过该干员的历史剧情/首通解锁，在开局选择时可选 |
| 未解锁 | 灰色显示，需要通过特定大局的剧情事件解锁 |

> 解锁状态存储在 PlayerPrefs（与天赋树一样是永久的）。首次通过剧情获取某干员后自动解锁，之后每次开局都可以选择。

## 四、局内干员持有系统

### 4.1 干员名册（OperatorRoster）

```
RogueOperatorState
├── operatorDataId    (string)  — 对应 OperatorData 的名字/ID
├── maxStarRating     (int)     — 星级上限（1~5，不变）
├── currentStar       (int)     — 当前星级（1~maxStarRating，可强化提升）
├── isInitial         (bool)    — 是否开局选中的干员
├── acquisitionMethod (enum)    — 获取方式（Selection / Story / Encounter / Shop）
├── sourceActId       (int)     — 在哪个大局获得的
└── unlocked          (bool)    — 是否已永久解锁（跨大局保留）
```

| 参数 | 值 | 说明 |
|------|-----|------|
| 开局星数预算 | 7 | 选中干员 currentStar 之和 |
| 大局内阵容上限 | 8 | 一个大局内最多持有 8 名干员 |
| 跨大局携带上限 | 5 | 通关大局后选 5 名带入下一个大局 |

### 4.3 战斗中的干员卡牌

- 战斗场景中的「角色画布」改为**从 RogueRuntimeState.OperatorRoster 动态生成 OperatorCard**
- 玩家在关卡间可以调整出战阵容（在 plot 地图界面操作）

## 五、干员获取系统

### 5.1 获取方式总览

| 方式 | 时机 | 费用 | 说明 |
|------|------|------|------|
| **开局自选** | RogueEntry 界面 | 免费 | 从已解锁干员中选初始队伍 |
| **剧情获取** | 特定关卡/节点 | 免费/金币 | 策划在 ActConfig 手动配置 |
| **奇遇获取** | 奇遇事件节点 | 免费/金币 | 部分奇遇选项奖励干员 |
| **商店概率** | 商店节点 | 金币 | 60% 概率刷新出可招募干员 |
| **商店剧情** | 商店/休息节点 | 金币/免费 | 策划安排的剧情事件 |

> 新获取的干员默认 currentStar=1，需要花费金币强化星级。

### 5.2 剧情获取（主路径）

策划在 ActConfig 中配置"剧情干员获取点"：

```csharp
[System.Serializable]
public class StoryOperatorAcquisition
{
    public int nodeIndex;
    public string operatorName;
    public string storyTriggerId;
    public bool isFree;
    public int cost;
    public string joinReason;
}
```

**示例**（大局 1 · 魔王的试炼）：

| 节点 | 干员 | maxStar | 剧情原因 |
|------|------|---------|---------|
| 节点 3 | 武士 | ★★★ | "武者流浪至此，愿同行" |
| 节点 7 | 牧师 | ★★★ | "神殿牧师感念你的使命，决定随行" |
| 节点 12 | 铁壁 | ★★★ | "佣兵要求预付佣金才肯加入"（30 金币） |
| 节点 18 | 奥术 | ★★★★ | "被囚禁的术师获救后自愿加入" |

> 剧情获取的干员同时**永久解锁**，之后开局自选时也可以选。

### 5.3 奇遇获取

部分奇遇事件选项奖励干员（从未持有的同星级上限干员池随机抽取）。

### 5.4 商店概率刷新

| 参数 | 值 |
|------|-----|
| 出现概率 | 60% |
| 货位数量 | 1~2 |
| 招募价格 | 按 maxStarRating：1星=10金 / 2星=20金 / 3星=40金 / 4星=80金 / 5星=150金 |

### 5.5 放弃干员

- 剧情/奇遇获取的干员放弃时不返还金币
- 商店购买的干员放弃时返还 50% 金币
- 开局选中的干员不可放弃

## 六、星级强化系统

### 6.1 强化机制

消耗金币提升干员 currentStar：

| currentStar → 下一星 | 费用 | 属性倍率变化 |
|---------------------|------|------------|
| ★1 → ★2 | 20 金币 | ×1.0 → ×1.3 |
| ★2 → ★3 | 50 金币 | ×1.3 → ×1.7 |
| ★3 → ★4 | 100 金币 | ×1.7 → ×2.2 |
| ★4 → ★5 | 200 金币 | ×2.2 → ×3.0 |

> 强化受 maxStarRating 限制。强化在商店/休息节点可用。

### 6.2 属性计算

```
最终属性 = OperatorData 域始值 × baseStatMultiplier(maxStarRating) × starGrowth(currentStar)

baseStatMultiplier: maxStar=1→0.6, maxStar=2→0.8, maxStar=3→1.0, maxStar=4→1.3, maxStar=5→1.6
starGrowth: ★1→1.0, ★2→1.3, ★3→1.7, ★4→2.2, ★5→3.0
```

**示例**（战术先锋 maxStar=3, ATK=21）：
- ★1（初始）: 21 × 1.0 × 1.0 = 21
- ★2（强化1次）: 21 × 1.0 × 1.3 = 27
- ★3（强化2次）: 21 × 1.0 × 1.7 = 36

**示例**（近卫 maxStar=5, ATK=130）：
- ★1（初始）: 130 × 1.6 × 1.0 = 208
- ★2（强化1次）: 130 × 1.6 × 1.3 = 270
- ★5（强化4次）: 130 × 1.6 × 3.0 = 624

### 6.3 强化与天赋卡的叠加

```
最终属性 = (OperatorData 原始值 × baseStatMultiplier × starGrowth)  ← 星级系统
         × (1 + 天赋卡百分比加成)                                    ← 天赋卡
         × (1 + 天赋树百分比加成)                                    ← 天赋树
```

### 6.4 满星被动

干员达到 maxStarRating（满星）时解锁职业被动：

| 职业 | 满星被动 | 效果 |
|------|---------|------|
| 先锋 | 回费精通 | 部署后立即回复 3 DP |
| 近卫 | 专注强化 | 专注状态攻速 ×1.5→×1.8 |
| 重装 | 钢铁意志 | 致命伤保留 1 HP（每场限 1 次） |
| 狙击 | 致命瞄准 | 暴击率 +10%，暴击伤害 +50% |
| 术师 | 穿透精通 | 破甲比例 +15% |
| 医疗 | 紧急救护 | 目标 HP<30% 时治疗量 +50% |
| 特种 | 战术机动 | 技能冷却 -20% |

## 十四、FAQ

**Q: 为什么所有干员初始都是 1 星？**
A: 让玩家有成长空间。一个 maxStarRating=5 的干员在 1 星时已经比 maxStarRating=1 的强（×1.6 vs ×0.6），但还有 ×3.0 的成长上限。如果直接给满星，强化系统就没意义了。

**Q: 星数预算 7 会不会太少？**
A: 开局所有干员都是 1 星，7 点预算 = 最多 7 名干员。随着强化星级提升，星数会增长，但开局时 7 人已经足够应对前期。预算限制让"带几个低星工具人"还是"带少数高星核心"成为策略选择。

**Q: 天赋卡和干员为什么不混在一起？**
A: 天赋卡是"遗物"（被动加成），干员是"角色"。混在一起会削弱两种获取各自的乐趣。

**Q: 开局选的干员和剧情获得的干员有什么区别？**
A: 开局选的干员是 isInitial=true 不可放弃。剧情获得的干员可以放弃。两者都从 1 星开始，都可以强化。开局选的干员已经"永久解锁"，下次开局还可以选。

**Q: 撤退和阵亡的区别？**
A: 主动撤退返还 50% DP，冷却正常。阵亡不返还 DP，冷却 ×1.5。

**Q: 满星被动和精英 2 被动是什么关系？**
A: 满星被动 = 干员强化到 maxStarRating 时解锁的职业被动。取消了之前的"精英化"系统，改为星级强化系统，满星即解锁被动。

**Q: 放弃干员后能重新获取吗？**
A: 剧情获取的放弃后本局不再出现。商店购买的放弃后可能再次概率出现。但解锁状态永久保留，下次开局可以选。
