> 本文档整合自原 `REDESIGN_PLAN.md`、`Design_肉鸽塔防规划.txt`、`CLAUDE.md` 中一致且未过时的内容。

>
> **最后更新**：2026-08-13（基于代码实际状态；灵魂商店已确认废弃并改写为 7.2）

## 1. 游戏定位

**魔王肉鸽塔防**（类明日方舟 × 杀戮尖塔）：

- **题材**：玩家扮演"魔王"，在肉鸽地图上推进节点，部署干员防守守护点。
- **核心体验**：Build 多样性——每局通过选卡、商店、天赋树累积构建不同的流派。
- **差异化**：干员是"答案"，敌人是"题"；7 种敌人原型反克 7 种干员职业，双向克制避免万能解。

---

## 2. 核心循环

```
进入新局 → 选择节点(战斗/商店/休息/事件) → 战斗(部署干员防守守护点) →
→ 胜利：获得金币+抽卡次数+天赋点 → 选卡(3选1) → 继续推图 →
→ 守护点HP归零：时光回溯救场(1次，3选1必选) → 或 Game Over
→ 通关/死亡 → 结算天赋点(永久，死亡安慰) → 天赋树加点 → 再来一局
```

## 3. 节点系统

### 3.1 节点类型

| 节点 | Icon | 说明 | 当前状态 |
|------|------|------|---------|
| 普通战斗 | ⚔️ | 基础难度，胜利后选卡 1 次 | ✅ 已实现 |
| 精英战斗 | 💀 | 敌人套 EliteBuff，奖励翻倍(抽卡×2) | ✅ 已实现 |
| Boss 战 | 👑 | 每层最终 Boss，奖励最高 | ✅ 已实现 |
| 商店 | 🛒 | 金币购买卡牌 | ✅ 已实现(GoldShop) |
| 休息 | ❤️ | 恢复守护点 / 锻造 / 净化 | ✅ 已实现(Rest场景) |
| 事件 | ❓ | 随机事件（奇遇系统） | ✅ 已实现(RandomEvent场景, 31个事件) |
> 注：旧"灵魂商店"节点已废弃，其场景与入口已整体改造为天赋树界面（见 7.2）。

### 3.2 节点流程

采用 StS（杀戮尖塔）分叉路径地图：每个大局 21 个战斗节点（15 普通 + 5 精英 + 1 Boss），节点间分叉/合并。商店/奇遇/休息为节点间的穿插事件，不占按钮位置。

### 3.3 路线选择

`StSMapGenerator.cs` + `LevelMapController.cs` + `MapGraph.cs`：种子化路径分叉/合并/楼层规则约束，动态生成节点按钮 + 连线。`LevelNodeButton.cs` 点击节点进入 BattleScene，首通给首通金币加成(+20)。

## 4. 守护点系统（核心）

### 4.1 基础参数（`RogueBattleRunController` + `GameManager`）

| 参数 | 值 | 来源 |
|------|-----|------|
| 守护点最大 HP | 10 | `guardianMaxHp` (每场重建) |
| 守护点初始 HP | 10 | `guardianCurrentHp` |
| 时光回溯次数 | 1（可被救场卡增加） | `rewindSeconds = 5` |
| 回溯回退秒数 | 5 | `rewindSeconds` |
| 回溯后眩晕秒数 | 2 | `postRewindStunSeconds` |
| 紧急协议阈值 | 1 HP | `emergencyProtocolThreshold` |

### 4.2 守护点射击（`DefensePointShooter`）

| 参数 | 默认值 |
|------|--------|
| 射程 | 5.0 |
| 攻击间隔 | 1.0s |
| 攻击伤害 | 500 |
| 忽略防御 | false |
| 优先近处目标 | true |

### 4.3 时光回溯救场

守护点受致命伤 → 触发回溯（扣除 1 次）→ 回退 5 秒 → 从救场专用卡池 3 选 1（不可跳过，均为 PerBattle）。救场卡类型（`GuardianRewindTriggerType`）：即时 DP / 回复守护点 HP / 回复全体干员 HP / 冻结全场 / 伤害全场 / 击杀最弱 / 攻击 buff / 攻速 buff。

### 4.4 传送系统（`TeleportController`）

- 传送冷却：50 秒
- 可被守护卡缩短冷却、传送后加攻速 buff
- 干员可部署后传送到前线

## 6. 经济系统（三货币 + 押注）

### 6.1 货币体系

| 货币 | 变量 | 作用域 | 用途 |
|------|------|--------|------|
| 天赋点 | `TalentPoints` | 永久 | 天赋树加点（`TalentTreeState` 管理） |
| 金币 | `RunGold` | 局内 | 重抽/商店，通关清零 |
| 抽卡次数 | `CardDrawCount` | 局内 | 抽取天赋卡（免费选卡，战斗奖励获得） |

### 6.2 战斗奖励表（`BalanceConfig`，代码唯一真值）

> 每场战斗只有「通关」与「失败」两种结果，不再细分普通/完美等奖励档。

| 战斗类型 | 金币 | 抽卡 | 天赋点 |
|---------|------|------|--------|
| 普通 | 30 | 1 | 2 |
| 精英 | 45 | 2 | 3 |
| Boss | 70 | 3 | 4 |
| 失败 | 0 | 0 | 0 |
| 首通加成 | +20 | 0 | 0 |

### 6.3 死亡安慰

死亡/主动结束返还天赋点：`Base(1) + 通关层数 × PerStage(1)`。

### 6.4 押注系统（阶段 5 预留）

押注消耗抽象"代价"，四种概率路径（已配置未实装）：
- 不押 → 50% 概率得到额外奖励
- 押中 → 40% 概率双倍回报

### 6.5 局内消费

| 消费项 | 价格 |
|--------|------|
| 选卡重抽 | 10 金币（天赋树可减免） |
| 商店普通卡 | 15 |
| 商店进阶卡 | 30 |
| 商店稀有卡 | 60 |
| 商店传奇卡 | 120 |

## 7. 局外成长系统

### 7.1 天赋树（`TalentTreeState`）

永久解锁型成长，消耗天赋点。节点类型：属性加成 / 机制解锁 / 概率提升。卡牌效果通过 `TalentEffectApplier` 接入战斗系统。

### 7.2 ~~灵魂商店~~（已废弃）

旧方案：用"灵魂"（通关奖励）抽卡/购买永久增益，与天赋树互补（天赋树=线性稳定成长，灵魂商店=随机高方差）。**该方案已废弃，被天赋树完全取代**：原 SoulShop 场景与入口已整体改造为天赋树界面（场景控制器即天赋树 UI，标题与货币显示均为天赋点）。当前局外永久成长只有天赋树一条线，"灵魂"货币不存在。

### 7.3 收藏系统（`StoryCardCollection`）

剧情碎片收集系统：收集故事卡片解锁 Naninovel 剧情片段，增加重玩价值。翻页网格展示，支持锁定/解锁状态显示。

## 8. 战斗系统概要

### 8.1 干员

- 7 职业：先锋(Vanguard=0) / 近卫(Guard=1) / 重装(Defender=2) / 狙击(Sniper=3) / 术师(Caster=4) / 医疗(Medic=5) / 特种(Specialist=6)
- 属性：cost(部署费) / maxHealth / defense / attackDamage / attackInterval / attackRange / deployRadius / maxSP / purchaseCooldown
- 运行重算：`runtimeMaxHealth` / `runtimeAttackDamage` / `runtimeDefense` / `runtimeAttackInterval`
- 阻挡系统 (`UnitBlocker`)：`maxBlockCount` 控制近战阻挡数（先锋 0=不挡）
- 技能系统 (`OperatorSkill` 抽象基类)：6 种技能已实现（攻速/挡全攻/DP爆发/金身防御/破防/攻击强化/射程扩展）

### 8.2 敌人

- 19 个 EnemyData2 资产（其中 7 个为设计原型的七原型；其余为历史遗留 + Boss）
- 42 个 OperatorData 资产（29 旧干员 + 13 魔族角色）
- 属性：lives(HP) / defense / damage / damageForPlayer / speed / attackInterval / attackRange / dpOnKill
- 特殊开关：penetrateDefense / rangedAttack / healRadius+healPercentOfMax+healInterval
- 精英化：`Enemy2.ApplyEliteBuff(hpMult, defBonus, bonusDP)`
- 减伤公式：`reduction = Min(0.99f, defense / 10000f)` → 100防御=1%减伤，上限99%

### 8.3 刷怪点

- SpawnerHealth：maxHealth 200
- SpawnerShooter：射程4.0 / 攻速1.2s / 伤害300
