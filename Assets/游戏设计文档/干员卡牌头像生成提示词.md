# 干员卡牌头像 AI 生成提示词

## 通用风格要求（每次生成都要包含）

```
动漫风格，2D插画，奇幻塔防游戏角色半身像（胸部以上），正面或微侧角度，表情清晰可辨。
画风参考：日系动漫，深色奇幻风格，线条细腻，色彩饱和度高。
构图：人物居中，头部占画面60%-70%，能清晰看到脸部表情和发型。
背景：纯透明背景（PNG with alpha）或纯黑背景（#000000）。
尺寸：1024×1024 正方形。
不要包含：全身、武器道具遮挡脸部、复杂背景、文字水印。
```

## 使用说明

1. **第一组（1-7）**：把参考立绘图片和提示词一起发给AI，让它根据立绘生成半身头像
2. **第二组（8-21）**：直接用提示词生成，无需参考图
3. 生成后把图片保存为PNG格式，放入 `Assets/Sprites/OperatorPortraits/` 目录
4. 在Unity中设置 Texture Type = Sprite，导入后赋值给对应 OperatorData.asset 的 icon 字段
