# 卡片盲抽特殊场景设计

## 背景

原本卡片选择机制为"全盲抽"：玩家抽卡时只能看到卡片背面，点击后才翻开查看内容。

现已改为**默认显示正面**：玩家大部分时候能看到卡片的详细描述（名称、类型、稀有度、描述、图标），直接选择想要的卡片。

**盲抽模式（IsBlindPickMode）** 作为特殊机制保留，供设计者后续在特定场景中启用。

---

## 技术实现

### 核心标志位

```csharp
// RogueResultController.cs
public static bool IsBlindPickMode = false;
```

- `false`（默认）：卡片正面朝上，玩家可以看到完整信息并直接选择
- `true`：卡片背面朝上，玩家看不到卡片内容，点击后才翻开（即原始盲抽行为）

### 工作原理

| 流程环节 | IsBlindPickMode = false（默认） | IsBlindPickMode = true（盲抽） |
|---------|-------------------------------|-------------------------------|
| PickRandomOffers | `_slotRevealed[i] = true`，卡片正面直接显示 | `_slotRevealed[i] = false`，卡片背面朝上 |
| RefreshCardSlotVisuals | 显示 cardFront、icon、名称、描述 | 显示 cardBack，隐藏所有内容 |
| ShowCardTooltip | 悬停显示详细 tooltip | 悬停不显示 tooltip |
| RevealThenPick | 跳过翻卡视频/动画，直接执行选卡 | 播放翻卡视频/动画，再执行选卡 |
| 流程结束 | 自动重置 `IsBlindPickMode = false` | 自动重置 `IsBlindPickMode = false` |

### 自动重置

`IsBlindPickMode` 在以下4个退出点自动重置为 `false`，确保不会泄漏到下一次抽卡：

1. `RevealThenPick` 协程 - 中途退出（IsMidGameDrop 路径）
2. `RevealThenPick` 协程 - 正常结束
3. `OnSkipCardPick` - 中途退出（IsMidGameDrop 路径）
4. `OnSkipCardPick` - 正常结束

---

## 如何启用盲抽模式

在触发卡片选择前，设置标志位为 `true`：

```csharp
// 示例：在某个特殊事件触发盲抽
RogueResultController.IsBlindPickMode = true;
// 然后正常触发卡片选择流程...
```

**注意事项：**
- 必须在 `PickRandomOffers()` 被调用之前设置
- 无需手动重置，选卡流程结束后会自动重置为 `false`
- 与 `IsMidGameDrop`、`IsFirstStageDrop`、`IsGuardianRewindDrop` 等标志位兼容，可组合使用

## 待设计的特殊场景（TODO）

以下场景尚未设计，仅为构思方向参考。设计者可根据需要选用或自创新场景。

### 构思方向

1. **神秘商人/未知宝箱**
   - 场景描述：玩家遇到神秘商人，以更低代价抽取卡片但不知道内容
   - 设计意图：风险与收益权衡，低成本换取不确定性

2. **诅咒/混沌关卡**
   - 场景描述：某些关卡带有诅咒效果，强制盲抽
   - 设计意图：增加关卡差异化，制造紧张感
   - 可与关卡修饰器（Modifier）系统配合

3. **赌徒事件**
   - 场景描述：玩家可选择"明抽"或"盲抽"，盲抽有额外奖励（如多抽一张、稀有度提升等）
   - 设计意图：给予玩家选择权，而非强制盲抽

4. **Boss 战前奖励**
   - 场景描述：Boss 战前的特殊强化机会，卡片内容隐藏，增加挑战不确定性
   - 设计意图：Boss 战的紧张感前置

5. **剧情相关盲抽**
   - 场景描述：剧情需要，角色在"未知"状态下做出选择
   - 设计意图：叙事与玩法结合

### 设计要素清单

设计具体场景时，建议明确以下要素：

- [ ] 触发条件（什么情况下进入盲抽）
- [ ] 盲抽卡池（是否使用特殊卡池）
- [ ] 盲抽张数（是否与普通抽卡一致）
- [ ] 补偿机制（盲抽是否有额外奖励补偿不确定性）
- [ ] 是否可跳过（玩家能否选择不抽）
- [ ] 视觉表现（是否需要特殊的背面图案或特效）
- [ ] 与现有标志位的关系（是否同时为 IsMidGameDrop 等）
